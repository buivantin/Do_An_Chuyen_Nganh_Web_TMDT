## 3. Ý kiến của giảng viên (Chuyên đề Tiết 5)

- Nhắc nhở nhóm chú ý các lỗi bảo mật thường gặp: SQL Injection, XSS, CSRF.
- Cần kiểm tra kỹ dữ liệu phía Server (không tin tưởng dữ liệu từ Client).
- Các API quan trọng (như đăng nhập, thêm giỏ hàng) cần có cơ chế giới hạn tần suất gọi (Rate Limiting) để chống spam.
