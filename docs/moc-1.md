# BÁO CÁO MỐC 1 - ĐỒ ÁN CHUYÊN NGÀNH WEB
**Nhóm:** Nhóm 09 - **Đề tài:** Website Thương mại điện tử (Bán sách)

## 1. Tổng quan dự án
- **Công nghệ sử dụng:** 
  - Backend: Laravel 10+ (PHP 8.1+)
  - Frontend: React (Vite) + Tailwind CSS
  - Database: MySQL
- **Kiến trúc hệ thống:** Mô hình 3 lớp (Controller - Service - Repository). 
- **Quản lý dự án:** Trello (7 cột) & Git/GitHub (Git Flow, bảo vệ nhánh develop).

## 2. Tiến độ Sprint 1 (Tuần 1)
- **Đã hoàn thành:**
  - Thiết lập khung dự án, kết nối CSDL thành công.
  - Thiết kế ERD (chuẩn 3NF) và chạy Migration tạo 6 bảng + Seed dữ liệu mẫu.
  - Vẽ sơ đồ Use Case, Sequence Diagram (luồng đặt hàng).
  - Hoàn thiện API Đăng ký/Đăng nhập (băm mật khẩu bảo mật).
  - Dựng giao diện layout chung và trang chủ tĩnh (responsive).
- **Tài liệu đính kèm:** Đề cương, Use Case, ERD, Sequence, Wireframe, Test Case.

## 3. Kế hoạch Sprint 2 (Tuần 2)
- **Mục tiêu:** Hoàn thiện các chức năng mua hàng cốt lõi.
- **Phân công dự kiến:**
  - TV1 & TV2: Hoàn thiện API Giỏ hàng (TM-05) và Đặt hàng (TM-06).
  - TV3: Giao diện Giỏ hàng, Đặt hàng, Chi tiết sản phẩm.
  - TV4: Hoàn thiện API Quản lý sản phẩm (TM-12), danh mục (TM-11).
  - TV5: Kiểm thử quy trình mua hàng, viết test case.

## 4. Phân công thuyết trình Mốc 1 (10 phút)
- **TV1 (5 phút):** Giới thiệu tổng quan, công nghệ, kiến trúc và quản lý dự án trên Trello.
- **TV4 (2 phút):** Trình bày ERD và CSDL mẫu.
- **TV3 (2 phút):** Demo giao diện Trang chủ và Layout chung.
- **TV5 (1 phút):** Báo cáo quy trình Git và kiểm thử.
